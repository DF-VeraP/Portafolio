# Portfolio Web - Daniel Felipe Vera Perdomo

Portafolio web personal, desarrollado como una Single Page Application (SPA) responsiva y bilingüe (Español e Inglés). 

## Características
- **Tecnologías:** HTML5, CSS3, JavaScript (Vanilla).
- **Estética:** Tema oscuro con acentos de color neón.
- **Funcionalidades:** 
  - Cambio de idioma (ES/EN) con persistencia en localStorage.
  - Efectos visuales de máquina de escribir y animaciones en el scroll.
  - Formulario de contacto.
  - Lector y descarga de CV integrado mediante ventana emergente.

## Despliegue
Este proyecto contiene archivos estáticos (HTML, CSS, JS, e imágenes), por lo que puede ser desplegado fácilmente en cualquier servidor web (como Nginx, Apache) o servicios de alojamiento estático (GitHub Pages, Netlify, Vercel).
