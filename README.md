# Portfolio Web - Daniel Felipe Vera Perdomo

Portafolio web personal, desarrollado como una Single Page Application (SPA) moderna, responsiva y bilingüe (Español e Inglés), desplegado en VPS con Docker y Nginx.

## Proyectos Destacados

1. **SIGI - Sistema de Información Geográfica de Incidentes**
   - Análisis y visualización espacial de incidentes en Florencia, Caquetá.
   - *Stack:* Node.js, Express, PostgreSQL, PostGIS, QGIS, HTML5/CSS3.
   - *Enlace:* [sigi.verapd.xyz](https://sigi.verapd.xyz/) | [GitHub](https://github.com/DF-VeraP/SIGI)

2. **COOPMONEY - Sistema Multicooperativa**
   - Plataforma de gestión financiera cooperativa (ahorro, crédito, socios y reportes).
   - *Stack:* Node.js, Express, PostgreSQL, JavaScript, HTML5/CSS3.
   - *Enlace:* [coopmoney.verapd.xyz](https://coopmoney.verapd.xyz/) | [GitHub](https://github.com/DF-VeraP/COOPMONEY)

3. **Gestor de Contactos - Android APK & Backend API**
   - Aplicación móvil Android para operaciones CRUD en tiempo real conectada a VPS.
   - *Stack:* Kotlin, Android SDK, Node.js, Express, REST API.
   - *Enlace:* [contactos.verapd.xyz](https://contactos.verapd.xyz/) | [App GitHub](https://github.com/DF-VeraP/apk_Andorid) | [API GitHub](https://github.com/DF-VeraP/server_Apk)

4. **Sistema de Juicios Evaluativos - SENA**
   - Procesamiento, análisis y consulta organizada de juicios evaluativos académicos a partir de hojas de cálculo.
   - *Stack:* React, Vite, JavaScript, Tailwind CSS, Node.js.
   - *Enlace:* [juicios.verapd.xyz](https://juicios.verapd.xyz/) | [GitHub](https://github.com/DF-VeraP/Juicios_Evaluativos)

5. **OCR - Extracción & Validación Documental** *(En desarrollo)*
   - Procesamiento inteligente de documentos PDF con identificaciones, segmentación OCR y contraste con registros Excel.
   - *Stack:* Python, Computer Vision / OCR, PDF Processing, Data Validation.

6. **SPEAKSOFT - Plataforma de Aprendizaje de Inglés** *(En desarrollo)*
   - Plataforma para el aprendizaje del idioma inglés con cursos interactivos, evaluaciones y calificaciones.
   - *Stack:* Full Stack, EdTech, Audio/Speech, Interactive UI.

## Características Técnicas
- **Frontend:** HTML5, CSS3 Vanilla con efectos Neón / Glassmorphism, JavaScript Vanilla.
- **Internacionalización (i18n):** Bilingüe (Español / Inglés) con persistencia en `localStorage`.
- **Despliegue:** Contenedor Docker con Nginx Alpine expuesto en VPS.
